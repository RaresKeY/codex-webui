# Automation and image design

The MVP supports UTC interval/cron creation, enable/disable, run-now, an in-process overlap lease, and completion status. Desired scheduling becomes a controlled project continuation: creation previews authority/timezone/next runs, every execution is inspectable, and users can edit, duplicate, view history, and pause. Unattended work defaults to restricted authority.

The MVP imports, lists, client-filters, refreshes, displays, and deletes app-owned image files. The desired library unifies uploaded, generated, and explicitly indexed workspace images without silently copying private trees, adding project/origin/date/format/dimension/tag filters plus attach, locate, download, association, and separate index/byte deletion.

## Gaps

- Decide unattended approvals, retries, notifications, and future condition triggers.
- Define full-decode/dimension safety, duplicate semantics, persistent metadata/tags, richer search, and whether generation is only surfaced from Codex events.
