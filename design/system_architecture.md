# Desired system architecture

Retain the Python modular monolith and the narrow Codex App Server adapter. React consumes normalized HTTP/WebSocket state. One backend chat operation owns Jev selection, a real acknowledged per-thread model/effort change and submission of the exact ask with explicit turn overrides. Its guarantee must hold for direct HTTP clients independently of the UI. Container tools and workspace mounts define runtime authority.

## Gaps

- Persisted event replay, negotiated protocol ranges and richer routing context need separate contracts.
