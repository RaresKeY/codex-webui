# Desired system architecture

Retain the Python modular monolith and the narrow Codex App Server adapter. React consumes normalized HTTP/WebSocket state. Jev is a typed, server-owned advice boundary; apply the choice through an acknowledged per-thread model change and explicit turn overrides. Container tools and workspace mounts define runtime authority.

## Gaps

- Persisted event replay, negotiated protocol ranges and richer routing context need separate contracts.
